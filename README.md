# Business Analytics Dashboard

## About the Project
BizAnalytics is a business analytics dashboard built using React. It presents business sales data in a simple and interactive dashboard.

## Features
- Sales and revenue summary cards
- Monthly sales bar chart
- Product category doughnut chart
- Revenue trend line chart
- Recent sales table
- Search sales records
- Add Sale interface
- Export sales data to CSV
- Dark theme UI

## Technologies Used
- React
- Vite
- JavaScript
- CSS
- Chart.js
- react-chartjs-2

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL displayed in the terminal.

## Note
This project currently uses sample data and is a frontend demonstration. It does not use a backend or database.
